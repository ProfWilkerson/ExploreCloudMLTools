Purpose: In Module 4 you examined the machine learning lifecycle: from problem framing and data preparation through model training, evaluation, and deployment. Real cloud platforms package many of those steps into products your organization might already subscribe to or evaluate. This activity connects those lifecycle concepts to a specific, widely used tool.

What to do: Follow the guided steps below to browse the AWS SageMaker Canvas product page. You do not need an AWS account. When you finish, answer the three reflection prompts and compare your thinking to the sample answers.

What is SageMaker Canvas? Amazon Web Services (AWS) is one of the three dominant cloud providers alongside Microsoft Azure and Google Cloud. SageMaker is AWS's machine learning platform, and Canvas is its no-code interface within that platform. It is designed so that business analysts and domain experts can build and deploy ML models without writing code, using the same underlying infrastructure that data science teams use.

1. Which stages of the ML lifecycle does SageMaker Canvas appear to support? Use the lifecycle vocabulary from Module 4 in your answer.

Sample Answer
SageMaker Canvas supports multiple stages of the ML lifecycle within a single tool. It covers data ingestion and preparation (connecting to data sources and cleaning data visually), model training (automated model building without code), model evaluation (accuracy metrics and model leaderboards displayed in the interface), and deployment and prediction (generating batch or real-time predictions and exporting results). It does not typically cover the earliest stage of problem framing, which happens before any tool is opened.

2. Is coding required to use SageMaker Canvas? What does the page suggest about who this tool is designed for?

Sample Answer
No coding is required. SageMaker Canvas is explicitly marketed as a no-code tool. The page uses phrases like "no code" and "point-and-click" and describes the audience as business analysts, line-of-business users, and domain experts who need ML capabilities without relying on a data science or engineering team. This positions Canvas as a tool that lowers the barrier to entry for ML, allowing people with deep domain knowledge but limited technical background to build and use predictive models.

3. What kinds of problems does SageMaker Canvas handle? Give at least two specific examples and connect each one to a learning type you studied in Module 4.

Sample Answer
SageMaker Canvas handles several ML problem types. Two clear examples:

Classification (for example, predicting whether a customer will churn or stay): This is a supervised learning problem. The model is trained on historical customer records that are labeled with the known outcome (churned or retained).

Time series forecasting (for example, predicting next month's product demand): This is also a supervised learning problem. The model trains on historical sequences of values with known outcomes to predict future values.

Both problem types rely on labeled historical data, which is the defining characteristic of supervised learning. Canvas automates the model selection and training process for each type, but the underlying approach is still supervised.
