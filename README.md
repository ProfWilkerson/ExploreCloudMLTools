# Explore: Cloud ML Tools Browse

**Course:** AI Essentials
**Module:** 4
**Type:** Non-graded exploration activity

## Overview
A guided browse-and-reflect activity built around the AWS SageMaker Canvas product page. Students visit the live AWS page (no account required), work through four structured observation steps, and then answer three reflection prompts connecting what they observe to the ML lifecycle concepts and learning types covered in Module 4. Reflection answers are self-revealed for comparison.

## File
`index.html`: single self-contained HTML file, no dependencies or external libraries required. Contains a direct link to the AWS SageMaker Canvas page.

## Instructor Notes
- No AWS account or login is required to browse the product page.
- The activity links directly to `https://aws.amazon.com/sagemaker/ai/canvas/`. AWS updates product pages periodically; review the live page before each module delivery to confirm the content students will encounter still aligns with the guided steps.
- A note is included in the activity reminding students that page content may have changed and to apply lifecycle vocabulary to whatever they find.
- Reflection questions are for student self-assessment only. No submission is expected.
- The activity pairs well with the "What Learning Type Is This?" exploration in the same module.
